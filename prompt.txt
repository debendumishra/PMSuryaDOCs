

Develop a **production-ready Android application** using **Kotlin**  with **Jetpack Compose**, **Material 3**, **MVVM + Clean Architecture**, **Repository Pattern**, **Room Database**, **Hilt Dependency Injection**, and modern Android development best practices.

The application is designed for **PM Surya Ghar document processing**. Its purpose is to automate document organization, PDF creation, AI-assisted verification using the **Gemini Android App (via Intent)**, report generation, ZIP creation, and WhatsApp sharing.

**Important:** The application **must not use the Gemini API**. It must interact with the **installed Gemini Android application using Android Intents**.

---

# Core Workflow

The application **does not continuously monitor WhatsApp**.

The processing begins **only when the user presses the "Start Processing" button**.

Overall flow:

1. User receives documents in a predefined WhatsApp chat.
2. User opens this application.
3. User presses **Start Processing**.
4. Application reads all newly received supported files from the configured WhatsApp source since the last successful processing.
5. Application groups the documents.
6. Converts every document into compressed PDF. except rooftop as jpg
7. Launches Gemini using Android Intent with all PDFs, jpg 
8. Gemini analyzes every document and returns the required information. as per prompt given by user
9. User shares/copies Gemini response back into the application.
10. Application extracts Customer Name and Mobile Number from the Gemini response.
11. Application displays the proposed output folder location in settings
12. User may edit the folder name/location if desired.
13. Application creates the folder.
14. Saves all PDFs.
15. Generates Word report.
16. Creates ZIP.
17. Opens WhatsApp with ZIP attached for sending to the configured destination number.
